- Tests accompany every vertical slice. Installed native-panel evidence cannot be replaced with mocks or overlay screenshots.
- Owner-approved reference comparisons are required; regenerated screenshots alone do not prove Vue parity.
- No fabricated runtime data, component fixtures, store records or timeline events in production.
- Preserve the 80% global coverage gate and existing checks; browser prerequisites must fail closed.
- R38 closes only after fresh-profile UAT, owner approval and actual approved/signed public distribution. A GitHub release or pending store submission is not public-browser readiness.
- Add new scope only for demonstrated blockers; do not silently expand the approved finite backlog.
